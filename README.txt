# 🌻 Flores Amarillas

Proyecto web romántico realizado con HTML, CSS y JavaScript.

## Abrir en el teléfono

No necesita instalación.

### Forma 1 — desde el computador
Abre `index.html` con Chrome, Edge o Firefox.

### Forma 2 — publicarlo en Internet
Puedes subir toda la carpeta a un servicio de alojamiento estático como GitHub Pages, Netlify o Vercel y compartir el enlace desde WhatsApp.

## Personalizar el mensaje

Edita `index.html` y cambia los textos dentro de:

- `<h1>`
- `<p class="intro">`
- `<h2>`
- Los párrafos de `.card`

## Agregar música

Coloca un archivo:

`audio/musica.mp3`

y adapta `js/app.js` para reproducirlo mediante un botón. Los navegadores móviles normalmente requieren que la reproducción comience después de una interacción del usuario.
